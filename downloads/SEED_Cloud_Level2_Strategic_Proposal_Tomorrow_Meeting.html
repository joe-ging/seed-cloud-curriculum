軸線 2：【Incorporate AI】老闆核心綱領與 Level 2 精準定位

根據老闆下發的《AI Enhancements for Cloud Course vJul2026》與《AI enhancements ideas MASTER》，課程對 AI 劃分了三層嚴密體系，我們負責的 Level 2 (Beginner) 官方定位是： 👉 【AI-Assisted Cloud Operator】（AI 輔助雲端運維與操作者）

老闆規劃之四大模塊 具體教學任務 採用工具 (Tools) 核心學習價值
1. AI CLI Helper
(終端命令智能輔助)		 學生使用 AI 解釋複雜 Linux、SSH、Nginx、Git、curl 命令及各種報錯日誌 (Error Logs)。 Microsoft Copilot web 消除 15~18 歲中學生對黑底命令行終端的恐懼感，快速讀懂報錯。
2. AI API Integration
(AI 接口雲端調用)		 學生在 Web 前端透過簡單 JavaScript 調用後台的 AI 端點 (Endpoint)。 Cloudflare Workers AI
(老師/SEED 託管端點)		 讓學生認知：AI 不僅是聊天框，更是雲端標準的 API 服務！
3. AI Processing Workflow
(數據流動處理)		 構建全鏈路：輸入數據 ➔ 雲端 AI 處理 ➔ 保存結果。 Cloudflare Workers + Workers AI + D1/KV 將雲端算力、數據存儲與 AI 串聯為完整工程流。
4. Responsible AI Use
(負責任的 AI 安全)		 學習隱私保護、成本限制 (Cost Limits)、存取權限控制，以及主動核驗 AI 生成內容。 Cloudflare Dashboard / Logs + Copilot 樹立負責任的雲架構與 AI 使用習慣。

💡 二、 落地痛點攻堅方案：資源與 IDE 解決之道 (完全落實老闆方案)

針對 Wanda 與教研團隊提出的兩大核心顧慮，結合老闆文檔中的明確指示，我們在明天會議上給出無懈可擊的落地對策：

痛點 A：雲端與 AI 資源貧瘠（香港無信用卡、AI 服務受限）

Wanda 的顧慮：學生沒有國際信用卡，無法註冊 AWS/GCP；主流商業 AI 在香港有地區限制或學校網絡限制。

🛠️ 老闆文檔敲定的破局對策 (Zero-Cost & Safe-Failure Architecture)：

  1. Cloudflare 老師/SEED 託管架構 (解決年齡與信用卡限制)：
    • 老闆文檔明確指出：“Cloudflare accounts cannot belong to students (age restriction). The teacher's Worker endpoint must send CORS headers, so students can call it.”
    • 免信用卡與零超額扣費：
      • Cloudflare Workers 每天 10 萬次免費請求；
      • Workers AI 每天 10,000 Neurons 免費額度；
      • 安全失敗模式 (Safe Failure Mode)：“Never attach a payment method to the accounts. Exceeding limits produces errors, not billing!” 帳號不綁卡，超額只會報錯，絕無財務扣費風險！
  2. Microsoft Copilot Web (香港學校合法合規)：
    • 香港大部分中學已有微軟教育生態，copilot.microsoft.com 在中學校園網絡完全暢通，免翻牆、免付費。
  3. QF2 評核安全紅線（原版實驗 100% 兼容）：
    • 老板在文档中给出绝妙方案：“Add an 'AI use' line to existing lab sheets (prompt used + how output was verified) — keeps the 60/40 assessment intact!”
    • 在现有的实验纸上只加一行“你使用的 AI 提示词是什么 + 你是如何核实输出正确性的”，直接保全港大進修學院 QF2 60/40 考核標准，不推翻現有實驗！

痛點 B：學校硬體門檻（無電腦、僅 iPad/Chromebook、機房無安裝權限）

香港現狀：香港中學普及 BYOD（學生自帶 iPad 或 Chromebook），即便在電腦室，機房也有嚴格的權限鎖，學生根本無法下載安裝本地 IDE！

🛠️ 老闆文檔敲定的純瀏覽器 (Browser-Based) 免安裝工作流：

  1. 在線 Web IDE：JSFiddle / CodePen / GitHub Codespaces：
    • 老闆文檔指定：JSFiddle (jsfiddle.net) 或 CodePen 作為在線編程沙箱；
    • 任何 iPad、Chromebook 的 Safari/Chrome 點開即用，無需註冊或安裝；
    • 課堂四步工作法：“enforce a 'predict → paste → test → explain' routine”（先預測結果 ➔ 粘貼代碼 ➔ 測試運行 ➔ 學生解釋原理）。
  2. 學校 IT 白名單極簡清單 (提前提供給學校網管)：
    • copilot.microsoft.com
    • teachablemachine.withgoogle.com
    • jsfiddle.net
    • dash.cloudflare.com
